Data and cursory processing scripts for Sparta, NC gravity data.
See Levandowski, 2026 Seismological Research Letters 
(Lithologic controls on the 2020 Mw5.1 Sparta, North Carolina (USA) earthquake 
  illuminated by a gravity investigation of the Little River Fault and epicentral zone)

Run SpartaGravity_Main.m to produce residual gravity anomaly model and gridded models, 
  including Bouguer, residual, and high-pass filtered residual
